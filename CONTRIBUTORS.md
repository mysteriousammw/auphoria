# Contributors

AUPHORIA is a small project that grew from one idea into a tool. This page
credits the people who created, reviewed, built, and tested it, and the AI
assistants that helped write the code and documentation.

## Who we are

AUPHORIA is built and guided by a small team. The people behind it work
across livestock genomics, animal genetics and reproduction, infectious
disease, and cardiovascular regeneration in zebrafish, together with an
open-source software lead. We share a common goal: a free, simple, honest
data-analysis tool for students who cannot code.

## AI assistance

AI tools helped create this project. All results the software produces come
from deterministic open-source libraries, not from an AI model. Maintainers
are responsible for the content and for checking it.

- **Claude (Anthropic)** — AI assistant used for concept review, the project
  brochure, and the phased build prompts.
- **Hermes (Nous Research)** — AI coding agent used to write the repository
  code and documentation from those prompts.

## How to be listed

Open an issue or pull request asking to be added (for example with a short
description of your contribution) and the maintainers will add you here.
Listing a name means explicit permission was given to be credited.
