This directory holds research notes supporting analysis choices in AUPHORIA.

Expected contents (added as work proceeds):

- Literature references behind statistical choices (e.g., why Welch's t-test
  is the default; reference examples used to hand-check test answers).
- Trade-off analyses (e.g., effect-size conventions, missing-data policy).
- Validation studies — see `../validation/` for the standing validation
  policy; nothing in AUPHORIA is labelled "validated" yet.

Each note should be a dated markdown file with sources cited inline.
