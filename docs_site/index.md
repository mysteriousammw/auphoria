# AUPHORIA

**Beginner-friendly data analysis for university students who cannot code.**

AUPHORIA runs **entirely on your own computer or in Google Colab** — no server,
no account, no uploads, no internet after installation. It takes a spreadsheet
or CSV, guides you to the right statistical test, runs it for you, and writes a
plain-English report you can copy into your thesis.

## Is this for me?

This tool is made for a student writing a project, thesis, or paper who:

- has **data in a spreadsheet** (CSV, TSV, or Excel),
- needs a statistical test but does **not** know which one or how to code it,
- wants **honest, reproducible** output they can paste into a document,
- wants it to **work offline** on a laptop or in the free Google Colab.

If you can write code, you might not need AUPHORIA — but it will still save you
the plumbing.

## What you'll get

- A guided, plain-language walkthrough (no code required).
- An advisor that asks one question and suggests which analysis fits your data.
- A full report: numbers, figures, a paste-ready methods paragraph, and "what
  this result does **not** tell you."
- Reproducibility: every run saves the command and random seed so someone can
  re-run it and get the same numbers.

## A note before you trust a number

AUPHORIA computes honestly and checks assumptions, but **it does not certify
your science.** Read [Responsible use](responsible-use.md). If a number looks
wrong, [report it](known-issues.md) — validation of every
analysis is tracked on the [Validation](validation.md) page.
